• Briefly explain what your Java program does.
Tig arrange sa mga numbers gikan sa pinakagamay hangtod sa pinakadako gamit ang tulo ka sorting methods: Bubble Sort, Selection Sort, ug Insertion Sort. 

• Explain how Bubble Sort works.
Ang Bubble Sort e compare niya ang duha ka tapad nga numbers. Kung mas dako ang iyang abay, mag baylo sila ug position hangtod ma sort tanan.

• Explain how Selection Sort works.
Ang Selection Sort mag sugod sa pinakagamay nga number ug ibutang sa pinaka una. Buhaton niya hangtod ma arrange ang tanan numbers.

• Explain how Insertion Sort works.
Ang Insertion Sort magkuha ug number tapos ibutang niya sa sakto nga position hangtod ma sort tanan.

• Discuss the differences between the three sorting algorithms.
Lahilahi sila ug pamaagi sa pag sort. Ang Bubble Sort mag baylo sa iyang tapad nga numbers, ang Selection Sort mangita sa pinakagamay, ug ang Insertion Sort mangita sa sakto nga position.
